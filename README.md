# JANDUG_SEMI_ACTIVITIES

Completed implementations based on the uploaded laboratory activity sheet and the provided lessons.

## Requirements
- Python 3.10+
- pygame 2.1+
- PyOpenGL 3.1+ for Activity 5

Install:
    pip install pygame PyOpenGL PyOpenGL_accelerate

## Activity 1
Run `activity_1.py`.
- Key 1: Tweening
- Key 2: Polygon morphing
- Key 3: Bouncing dynamics
- ESC: Quit

## Activity 2
Run `activity_2.py`.
- Arrow keys: Move player
- R: Restart after game over
- ESC: Quit

## Activity 3
Run `activity_3.py`.
This is a console-based verification program. It verifies:
- P(2,-1,7) to Q(1,-3,5) distance = 3.0
- Sphere center (-2,3,-1)
- Radius sqrt(8) = 2.828
- 100-object sphere and AABB broad-phase tests

## Activity 4
Run `activity_4.py`.
- 1: Orthographic
- 2: Cavalier Oblique
- 3: Cabinet Oblique
- 4: One-Point Perspective
- W/S: Rotate X
- A/D: Rotate Y
- Q/E: Rotate Z
- ESC: Quit

## Activity 5
Run `activity_5.py`.
Requires PyOpenGL and an OpenGL-capable environment.
- Double-buffered OpenGL window
- Perspective projection
- Depth testing
- Colored cube
- Continuous rotation
- Hierarchical articulated arm
- Alpha blending
